# EMT Foods Exports

Public website and separate admin dashboard for EMT Foods Exports.

## Run Locally

```powershell
cmd /c npm install
cmd /c npm run dev
cmd /c npm run dev:admin
```

Public site: `http://first  localhost:3003`

Admin dashboard: `http://localhost:3001`

You can also double-click `run_app.bat` to start both servers in separate windows.

## Build And Check

```powershell
cmd /c npm run lint
cmd /c npm run build
cmd /c npm run build:admin
```
